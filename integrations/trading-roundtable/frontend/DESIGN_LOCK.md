# 视觉锁定 / Agent 接入边界

**这个目录是已经实现的设计源代码，不能根据文字说明再次重新生成 UI。**

交给 Agent 的工作范围：

1. 将 `src/App.tsx` 中 `readDashboard()` 的服务地址改成现有后端实际地址，或实现接口适配层。
2. 用真实 `QuantPageData` 替换 `demoData`，从数据库加载全部十席位配置；**不要填充不存在的角色、行情、策略结论**。
3. 保持五层 SVG 漏斗的绘制结构和布局；若更改层数，用数据映射生成层级，不能改成进度条列表。
4. 保留 `src/styles.css` 的配色、圆角、阴影、间距、动画以及移动端断点。可扩展但不要推翻。
5. 保留四位已知角色 `public/avatars/*.webp` 的视觉资源。第 5～10 位角色待配置；有真实画像后再替换。
6. 验收时对照 `funnel-preview.png`、`seats-preview.png`、`mobile-preview.png`。若数据不同导致数字不同可以，但版式和视觉语言必须一致。

约束：策略计算、选股信号、仓位建议、交易决策都不由前端动画产生；没有实时推送数据时，不得显示假进度。只负责展示后端事实和状态。

## 视觉基准

- 全局：暖灰 `#f5f3ef`，深蓝 `#11263c`，古金 `#c58a42`，白纸 `#fffdfa`。
- 核心布局：76px 左侧导航、顶部品牌栏、四个指标卡、左漏斗/右规则面板、底部入口。
- 第二页：桌面端双列角色席位、移动端单列，头像左侧 / 内容右侧，点击打开详情抽屉。
- 性能：动效以 transform/opacity 为主，尊重 `prefers-reduced-motion`。
