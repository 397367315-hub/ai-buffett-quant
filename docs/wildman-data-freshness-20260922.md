# 野人哥交易日期与刷新修复

## 原因

2026-09-22 凌晨复现：不指定日期的强制刷新返回 2026-09-18，虽然刷新时间已是当天。原逻辑以猫爪情绪日报的最新日期决定整个看板日期；工具箱也用该日报覆盖请求日期。

当次实测猫爪交易日历已返回 2026-09-21，但情绪日报只到 18 日。21 日涨跌停池接口一度返回未找到数据，东方财富同日备用接口可用。

## 修复

- 默认分析日改用猫爪交易日历，检查上海时区、开盘边界、休市和未来日期；盘前使用上一交易日。
- 日历使用 60 秒内存缓存，主动刷新绕过缓存。
- 工具箱保留明确的交易日请求；经日历确认的休市请求回到上一交易日。
- 刷新传递至情绪日报和涨停、跌停、炸板池，并用新响应更新有界缓存。
- 情绪日报缺少目标日期时合并数据库已有同日资料，不把历史日报改写为当天数据。
- 页面分别显示分析交易日、实际行情日期、情绪日报日期、刷新时间及涨跌停池实际来源。
- 继续优先猫爪；备用来源必须通过同日校验。

不增加数据表或原始行情长期存储，不修改主线五步规则、战法公式或交易权限。

## 验证

- 野人哥、NumCat、采集器和 Level-2 回归：238 项通过。
- 缓存回写与边界修正后针对性回归：97 项通过。
- 前端类型检查及生产构建通过。
- 本地真实数据刷新：分析日 21 日，涨停/跌停/炸板均为 21 日，20 个主线候选、149 只观察股；当时情绪日报仍为 18 日并明确标记。
