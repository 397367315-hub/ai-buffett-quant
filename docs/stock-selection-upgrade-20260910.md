# 选股功能升级记录（2026-09-10）

本次修改位于 workspace/ai-buffett-quant。本地升级已完成，线上状态以部署验收记录为准。

## 已实现

- 新增综合、启动观察、趋势延续、回调企稳、基本面改善五种研究方向。启动、回调和基本面初筛使用完整行情候选来源，避免仅从涨幅榜中寻找；完整行情不可用时保留数据缺口，不能冒充完整扫描。
- 快速/深度分析仍分别限制为45/80只，以控制计算量；候选来源分层进入深度研究。
- 研究分至少72、数据质量可用、审计无阻断及高风险、无硬性风险，才可进入合格候选。观察和排除名单分别保留原因；合格候选允许为0。
- 同行业上限默认为2只，可设0取消。超出行业或展示名额的候选转为观察，不默默丢弃。
- 机会卡分别展示研究类型、资格、确认状态、后续验证、失效条件、证据日期及参考价格。列出确认条件不等于条件已满足，类型名称也不代表形态已成立。
- 可从不同名单选择最多3只股票比较；移动端采用卡片并可直达研究详情。
- 保存规范化筛选参数；历史回顾只与最近100次记录中参数一致的较早记录比较，解释新增、保留、移出及资格变化。旧记录缺少新参数时标记不可同条件比较，旧名单显示历史未复核。
- 历史观察表现只统计当时的入选名单，观察名单不计入成绩；区分有效样本、观察期未完成与数据缺失。

## 历史表现的边界

观察起点晚于记录创建日期与原行情日期中较晚者，基准固定为之后第一个已记录市场交易日的收盘；缺少该股票首日或中间日线时不顺延窗口。只读取本地已收盘且明确标记复权、来源一致的日线。

5/10/20期按本地已记录市场交易日计数，完整交易日历尚未核验。未核验复权口径的历史缓存不展示收益数字。观察收益未扣成本，不代表可成交收益或实盘业绩，当前未加入基准指数超额收益。
