# 猫爪 MeoZ 数据补源审计

更新时间：2026-09-01

## 接入原则

- API Key 只保存在后端环境变量 `MEOZ_API_KEY`，不进入前端、日志或仓库。
- 猫爪有结构化数据时优先使用；东方财富、腾讯和 FTShare 保留为失败回退。
- 缺失字段保持 `null`，不写成 `0`，不从日 K 反推真实竞价或 Level-2 历史。
- 每条业务数据保留来源和数据日期；两融、龙虎榜和财报数据不标记为盘中实时。
- 数据字段以 `api-1.json` 和 `document.json` 的 OpenAPI 契约为准，`SKILL.md` 仅作为调用说明。

## 已保留原数据源回退

- 猫爪专线连接失败：只在配置允许的专线间切换；公网回退必须显式开启。
- 猫爪业务错误、鉴权错误或频率限制：不切换线路，交由业务采集器回退东方财富、腾讯或缓存。
- 两融板块聚合：猫爪当前资料只有市场和个股明细，现有东方财富板块聚合仍保留；失败时继续展示最近完整缓存。
- 北向资金：公开口径变化较大，继续沿用现有可验证成交统计，不制造净流入值。

## 不直接接入的内容

- 不执行资料中的客户端脚本 `meoz.py` 作为生产服务；系统使用自己的统一异步网关。
- 不把 `SKILL.md` 的说明当成选股规则或交易指令。
- 不把龙虎榜席位、封单额、主力净额解释为“庄家操控”或确定性买卖结论。
- 不将两融、财报、龙虎榜的盘后披露标记为实时行情。
- 不在没有真实时间戳时把竞价快照标记为实时。
